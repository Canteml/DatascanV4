# DatascanV2 Version 1.0.5 (31/08/2022)
	# Changements :
		- Modification :
			- Altimetre : La mesure dans l'entete n'est plus affiché si pas de mesure recu (objectif : aérer la visibilitée de l'interface)
			- Compatibilité Datareport : Les entêtes "pression", "humidité" empêchaient l'ouverture du fichier csv par datareport (suppression de ces entêtes maintenant)
			- Portes ASCAN : Intervertion de la couleur des portes (rouge / verte)

# DatascanV2 Version 1.0.4 (08/08/2022)

	# Changements :
		- Modification du processus d'enregistrement d'un AScan pour générer un BScan :
			- Pas d'arrondissement de la position vers le centre de la cellule la plus proche : on remplit la cellule sur laquelle le AScan se situe
			- En plus de remplir la cellule courante, on remplit les cellules voisines : potentielle perte de précision mais diminution des trous du BScan
			- La résolution a été laissée à 5mm par cellule, ceci validant toujours le CDC
		- Ajout des nouvelles fonctionnalités d'équipement :
			- Nettoyage (brosse + pompe), avec des boutons de contrôle dans l'IHM
			- Licence, avec une page d'informations dédiée
			- EndStop, pas de retour dans l'IHM
			- Compass
		- Ajout de retour capteurs pour les produits compatibles :
			- Capteur de température
			- Capteur d'humidité
			- Capteur de niveau d'eau dans les réservoirs
			- Capteur de pression
			- Boussole

	# Bugs résolus :
		- Fichier prepare_release.bat : un espace dans le chemin vers le dossier DatascanV2 mettait en erreur les commandes
